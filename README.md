# Cosmic JEV Extension

A dramatically simplified, extension-only spin-off of [Cosmic JEV](https://github.com/dgabriel/cosmic-jev): glows event cards green or red across a few event/conference listing sites, based on what Jev thinks of attending, from your real birth chart.

See [`docs/spec.md`](docs/spec.md) for the full spec — currently pending review, nothing implemented yet.
